The Studio works in this order:

1. **Data**: download or import prices.
2. **Build**: set up the strategy, its features and rules (or portfolio), risk and account.
3. **Backtest**: run it and read the tear sheet.
4. **Optimise**: search the values you choose, then check the results.

On this page, start from a template, open a saved strategy or a file, and save the current one. Your last edits are kept as a draft; if the browser reloads, the page offers to restore them.
