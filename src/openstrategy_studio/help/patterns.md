Each hit is judged as a trade from the next bar's open, bearish patterns as shorts, against the same trades taken on every bar. **Excess** is the difference.

Read the table with care: hits closer together than the horizon overlap, so t is optimistic, and with this many patterns some will look good by chance. **Add rule** adds the pattern as a feature and a condition on it to the rule you choose; confirm it with the optimiser's held-back test.
