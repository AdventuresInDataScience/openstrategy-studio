- **Look**: the page theme (it applies when the Studio next starts) and the default chart theme. **Make an editable copy** puts a theme file in your own folder to change.
- **Studio**: where all your data lives, how many processes an optimisation uses, and offline mode.
- **FRED rates**: a free key for interest-rate history, used for holding costs.
- **vectorbtX settings**: library-wide values such as the financing markup; blank keeps vectorbtX's default.

Press **Save settings** to keep changes.
