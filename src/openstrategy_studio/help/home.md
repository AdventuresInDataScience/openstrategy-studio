The Studio works in this order:

1. **Data**: download or import prices.
2. **Build**: set up the strategy, its features and rules (or portfolio), risk and account.
3. **Backtest results**: run it and read the tear sheet.
4. **Optimise**: search the values you choose, then read the jobs on **Optimiser results**.

Each visit starts with a blank strategy. On this page, start blank or from a template, open a saved strategy or a file, and save the current one. Your last edits are kept as a draft; if the browser reloads, the page offers to restore them.
